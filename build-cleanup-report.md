## Source cleanup decision

No source file is approved for removal in this consolidation pass. The strongest
candidates—SMPX crash-isolation builders, old material proof generators, and
one-off comparison composers—are untracked and still referenced by untracked
tests or reports. Removing them now would be a blind cleanup. They remain
clearly outside the new production command path and can be deleted later after
their useful regression assertions are migrated to focused tests.

## Scale evidence already available

The strict stock SLD scale report measures vanilla Militia x1 at **41 pixels**
feet-to-head/body height (x2: 82). The frozen accepted Hastati source is **172
pixels** at x1 (x2: 343). Therefore:

```
target x1 = 41 * 1.25 = 51.25 px
target x2 = 82 * 1.25 = 102.5 px
uniform image-height factor = mean(51.25/172, 102.5/343) = 0.2985
orthographic scale factor = 1 / 0.2985 = 3.350
new orthographic scale ~= 2.1707970809936525 * 3.350 = 7.273
```

The exact static rerender must measure its decoded result again because raster
thresholding can shift the visible height by one pixel. Scale is applied only
by an explicit fixed orthographic camera scale; no PNG or DAT scaling is used.
